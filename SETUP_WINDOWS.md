# Setup on your PC
1. Install Node 22+ and pnpm (`npm i -g pnpm`).
2. In this folder: `pnpm install --ignore-scripts`  (skips an optional terminal add-on that needs a C++ build)
3. `pnpm dev`  then open the URL it prints.
4. Add an Anthropic API key when the app asks (Settings), so the agent can chat.
5. Install UI skills into this folder (copy each install line from its ui-skills.com page).
6. `git init`, create a PUBLIC GitHub repo, push.
